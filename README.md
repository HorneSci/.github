# HorneSci on GitHub

This repository holds the [HorneSci organization profile](https://github.com/HorneSci) and the brand assets it uses.

Edit `profile/README.md` to update the public introduction. The light and dark headers use the approved HorneSci red-apex mark and outlined wordmark. `profile/assets/hornesci-avatar.png` is the organization avatar export.

For software, start with [HST Studio](https://github.com/HorneSci/hst-studio). For the company, visit [hornesci.com](https://hornesci.com).

See [brand notices](NOTICE.md) before reusing the identity assets.
